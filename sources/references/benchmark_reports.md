# 行业专业报告排版对标库（Benchmark Reports）

> 用途：持续打磨朴朴超市「合规资讯简报」自动化（日报/周报/月报）的格式与排版水准。
> 本文件为**纯研究+沉淀**，不修改任何报告生成器代码。所有链接均为具体深链（非官网首页根域名），便于对外追溯。

## 字段规范（每条样本必填）

| 字段 | 说明 |
| --- | --- |
| 机构 | 发布主体（上市公司/评级机构/四大/律所/监管机构/券商/研究机构） |
| 标题 | 报告全称 |
| 发布日期 | 真实发布日期；检索无法确认具体日时标注「约/年度」并说明依据 |
| 链接 | **可点击真实深链**（必须是具体文章页/PDF 直链，严禁官网首页根域名） |
| 可借鉴点清单 | 按下列 8 个维度提炼结构特征+可借鉴点（文字为主，不下载全文） |

**提炼维度（8 项）**：① 封面与品牌条 ② 自动目录与页码 ③ Executive Summary / 核心观点框 ④ 图表类型与配色（深蓝主色参考 `#1F3B63`） ⑤ 章节结构 ⑥ 页眉页脚 ⑦ 表格样式（斑马纹/表头/对齐） ⑧ 标题层级与防孤行（widow/orphan）处理。

## 跨样本共性提炼（可直接迁移到朴朴合规简报）

1. **「摘要/核心观点」前置**：11 份样本 100% 在正文前给出 Executive Summary 或核心结论框；我方日报/周报应在顶部设「本期要点 3 条」框。
2. **多级编号目录**：ESG 与研报普遍用「章|页码」右对齐目录；我方月报（较长）应启用自动目录+页码。
3. **图表必带「资料来源」脚注**：中金/中信/CAICT 均严格标注来源；我方所有图表须统一加来源行（可追溯硬性要求）。
4. **对比表/矩阵是合规类最高频结构**：金杜监管对比表、中信评级三态表、CAICT 框架图，均适合我方「监管水位对比矩阵」「行业合规要点清单」。
5. **配色收敛到同族深蓝**：腾讯/金杜/CAICT/中信均走蓝系专业色；我方主色 `#1F3B63` 与行业一致，需统一辅助色（建议 `+#C9A227` 金/或 `#E8EEF5` 浅蓝底）。
6. **固定尾部栏**：中信「评级说明+声明」、ESG「编制方法+鉴证」，提示我方应加「信息来源与免责声明」固定页脚栏。

## 可立即落地的排版优化建议（仅记录，待用户确认后再实施，不改代码）

> 以下建议基于本次 2026-09 对标，供后续迭代报告生成器时参考。

**建议 1（封面升级）**：对齐 PwC/腾讯 ESG 封面做法，在日报/周报/月报封面增加「机构品牌条 + 报告期 + 一句使命标语」，并将主色统一为 `#1F3B63`、辅助色限定为 1 个（建议金 `#C9A227` 或浅蓝 `#E8EEF5`），移除多余色块，提升专业感与品牌一致性。

**建议 2（新增图表类型：监管对比矩阵 + 框架图）**：参照金杜「欧美供应链合规对比表」与 CAICT「两横三纵框架图」，在月报中新增两类固定图表——①「监管水位对比矩阵」（行=法规/平台，列=要求/罚则/生效日/我方差距）；②「合规要点框架图」（框线+连接线表达风险→举措）。需同步落实「图表必带资料来源脚注」规范。

**建议 3（结构强化：核心观点框 + 自动目录 + 固定尾部声明栏）**：① 所有简报顶部固定「本期要点 3 条」核心观点框（对齐 11 份样本 100% 前置摘要的做法）；② 月报启用「章|页码」右对齐自动目录；③ 所有简报尾部加「信息来源与免责声明」固定栏（对齐中信证券研究尾部声明），满足对外可追溯要求。
